# Documentation

This directory contains the final documentation for the **LILO** (Locked-In Left-Out) project.

## Engineering Thesis

The primary document in this folder is the complete Bachelor of Science (Engineering) thesis:

* **Title:** Detecting the Presence of Living Beings Left in Cars Using Wi-Fi Channel Sensing
* **Author:** Filip Żurek
* **Supervisor:** prof. dr hab. inż. Katarzyna Kosek-Szott
* **Institution:** AGH University of Krakow
* **Faculty:** Faculty of Computer Science, Electronics and Telecommunications
* **Year:** 2026

## Contents

* **`Zurek_Filip_Detecting_the_Presence_of_Living_Beings_Left_in_Cars_Using_Wi_Fi_Channel_Sensing_2026.pdf`**: The full text of the engineering thesis. This document provides the theoretical background of Wi-Fi Sensing, describes the system architecture (ESP32, TinyML, MQTT), and presents the experimental results and performance analysis of the LILO system.
